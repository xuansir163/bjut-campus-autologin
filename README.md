# BJUT 校园网自动登录

北京工业大学寝室光猫网（认证页 `http://10.21.221.98/a79.htm`）的 Windows 自动登录工具。
掉线后自动完成认证，也支持开机 + 每 5 分钟定时检测的完全无人值守模式。

详细使用说明见 **[使用教程.md](使用教程.md)**。

## 快速开始

1. 安装 Python 3（勾选 Add to PATH）
2. 编辑 `config.json` 填入你的认证账号/密码/服务类型
3. 双击 `立即登录.bat` 测试
4. 双击 `安装开机自动登录.bat`（管理员）实现全自动

## 原理与实测要点

- 登录走 `eportal/portal/login` GET 接口，账号需带服务后缀（如 `@campus`）
- `lang=zh-cn` 与 `lang=zh` 必须同时存在，缺前者会被拒绝（Authentication fail）
- 返回 `512` 表示服务器认为该设备已在线，但**不代表真的有网**——可能是僵尸会话。
  脚本会先用 `online_list` 取本机真实 MAC/账号，定向登出后重登（旧版用假 MAC 登出会被服务器拒绝且被静默吞掉，导致"显示成功但没网"）
- `--force` 现在会真正登出：登出请求携带 `online_mac` + `user_account`，并复查会话是否已清
- 判定"在线"必须**会话存在 + 外网可通**双条件，避免假成功后不再重试
- `--status` 不需要 `config.json`，可直接用来排查（会打印会话 IP / MAC / 账号）
- 本机 IP 通过与认证服务器建立探测连接动态获取，适配任何设备
